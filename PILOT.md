# AGER Pilot Program

AGER is looking for 3–5 early design partners operating AI agents, voice agents, MCP integrations or production automations.

## Pilot outcome

The pilot creates an operational Agent Governance & Evidence baseline for one production deployment or a small deployment portfolio.

Deliverables:

1. Agent inventory and ownership record.
2. Tool, API and MCP permission map.
3. Autonomy classification A0–A4.
4. AGER Blast Radius assessment.
5. Human-control and kill-switch review.
6. Evidence register.
7. Change-event baseline.
8. Incident/near-miss record template.
9. Provisional SAFE-oriented incident export readiness.
10. Short management summary with prioritized gaps.

## Pilot pricing

**Founding pilot: EUR 0 setup for the first assessment** in exchange for structured product feedback and permission to publish an anonymized case study.

Optional continuation after the pilot:

- EUR 99/month for one small deployment portfolio
- custom agency pricing for multi-client deployments

No subscription is created automatically.

## Scope

AGER provides operational governance documentation and evidence workflows. It does not provide legal advice, certification, penetration testing or a guarantee of regulatory compliance.

## Ideal design partner

- AI/voice-agent agency
- automation agency using n8n, Make or custom agents
- MCP integration provider
- SaaS vendor with agentic features
- MSP operating AI systems for clients

## Pilot workflow

1. 30-minute discovery.
2. Deployment questionnaire/export.
3. AGER baseline generated.
4. Exposure review.
5. Feedback session.
6. Optional ongoing Governance Office service.
