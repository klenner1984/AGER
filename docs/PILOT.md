# AGER Founding Pilot

## Goal

Run AGER against one real production AI/voice agent and produce a useful operational governance baseline in a single working session.

## Pilot scope

For one selected agent, the pilot produces:

- AGER core record
- autonomy classification (A0–A4)
- tool/API/MCP inventory
- credential-scope and write-permission map
- data-category inventory
- human-approval and kill-switch review
- experimental Blast Radius score
- prioritized Exposure Scan findings
- evidence baseline
- incident/near-miss readiness record
- change-event baseline

## What the customer provides

- one production agent or representative deployment
- current tool/API/MCP list
- relevant permissions/scopes
- model/provider information
- owner/contact roles
- current human-review/approval controls
- existing evidence or logs that can be shared safely

No secrets, passwords or production credentials are required for the pilot.

## Deliverables

1. machine-readable AGER JSON records
2. concise human-readable findings summary
3. top remediation/control gaps
4. reusable baseline for future changes and incidents

## Founding-pilot commercial terms

The first founding pilots may be offered at no charge in exchange for structured product feedback and, only with explicit permission, an anonymized case study.

No legal compliance opinion, certification or security guarantee is included.

## Success criteria

The pilot is successful if the customer can answer, from the resulting evidence package:

- What does this agent do?
- What can it access?
- What can it change?
- Which actions require human approval?
- Who owns it?
- How can it be disabled?
- What changed since the baseline?
- What evidence exists if an incident occurs?
