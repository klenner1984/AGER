# telli x AGER — Founding Pilot

Status: proposal ready for existing telli thread
Owner: Andreas / wolf-systems
Scope: exactly one productive or production-like telli voice-agent deployment

## Goal

Prove in a bounded pilot whether AGER can turn one telli deployment into a repeatable operational evidence artifact for customer hand-off, governance review and incident readiness.

## Pilot inputs

Minimum information requested from telli for one selected agent:
- agent purpose and owner;
- model/provider and environment;
- connected systems/APIs/workflows;
- tool permissions and write capabilities;
- data categories handled;
- human approval / escalation / handover controls;
- change history available for the selected deployment;
- optional redacted logs or screenshots as evidence references.

No production credentials, API secrets or customer personal data are required for the pilot.

## Deliverables

wolf-systems delivers for one agent:
1. AGER Agent Governance & Evidence Record;
2. Exposure Baseline;
3. tool/API permission map;
4. autonomy classification A0–A4;
5. Blast Radius assessment;
6. human-control / escalation review;
7. evidence-reference baseline;
8. change-event starter record;
9. incident/near-miss readiness check;
10. short gap list with prioritized operational improvements.

## Pilot boundaries

- one agent only;
- free of charge;
- target turnaround: five working days after receipt of the agreed inputs;
- no certification;
- no legal opinion;
- no claim of official SAFE, OWASP, NIST or EU conformity;
- telli retains control over all supplied information;
- public case-study use only with separate written permission.

## Success criteria

The pilot is successful if telli can answer yes to at least three of the following:
- the record exposes relevant permissions or controls more clearly than the current hand-off documentation;
- the artifact is understandable outside the implementation team;
- the record can be refreshed after deployment changes without rebuilding the documentation from scratch;
- the evidence package would help internal review or customer hand-off;
- the format is reusable across additional deployments.

## Decision after pilot

No automatic paid conversion. A 20-minute review decides between:
- stop with no obligation;
- repeat for another deployment;
- AGER Office recurring service;
- technology/partner integration discussion.
