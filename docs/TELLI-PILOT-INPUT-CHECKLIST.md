# telli x AGER — Pilot Input Checklist

For one selected productive or production-like voice agent.

## Required

1. Agent name / internal identifier
2. Business purpose
3. Business owner and technical owner
4. Environment: demo / staging / production
5. Model/provider and relevant model version if available
6. Connected systems, APIs, webhooks, CRM, ticketing, databases or other tools
7. For each connection: read / write / execute capability
8. Human approval, escalation or handover points
9. Whether the agent can send external communications or modify production/customer data
10. Main data categories handled

## Useful but optional

- redacted architecture diagram;
- tool/permission screenshots;
- redacted change log;
- sample deployment release note;
- monitoring/alerting description;
- incident or near-miss example;
- existing customer hand-off documentation.

## Do not send for the pilot

- passwords;
- API secrets/tokens;
- private keys;
- unnecessary personal data;
- raw customer conversation data unless separately agreed and redacted/minimised.

## Fastest format

A short reply, spreadsheet, architecture screenshot or existing deployment document is sufficient. wolf-systems maps the supplied information into AGER; telli does not need to fill a new governance system manually.
